# 5 Most Important Topics

### js
JavaScript was the first thing I learned because React is built on it. Understanding functions, arrays, objects, map, and filter made it much easier for me to understand React and write code confidently.

### react
After learning JavaScript, I started React. It helped me build user interfaces in a more organized way. I learned how React makes it easier to create interactive web pages using reusable code.

### component
Components were one of the first React concepts I learned. They helped me break a large page into smaller parts, making the code easier to write, understand, and reuse throughout the application.

### router
Once I could create components, I learned Router to move between different pages. It helped me understand how React applications handle navigation without reloading the entire website.

### props
Props helped me pass data from one component to another. After learning components, props showed me how different parts of an application can communicate and display different information dynamically.
